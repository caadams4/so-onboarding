# First-week checklist

Tick these off with your buddy. Copy this file into your own notes; do not
commit ticks to this repo.

## Day 1
- [ ] Badge and desk
- [ ] Directory login and new password
- [ ] Mailbox working
- [ ] Authenticator app set up
- [ ] Team chat: `#welcome`, office channel, pod channel
- [ ] Laptop first boot finished

## Day 2
- [ ] Issue tracker and Pathnote sign-in
- [ ] `s1` installed
- [ ] VPN profile created and connected
- [ ] Strikeboard access requested through your pod lead

## Day 3
- [ ] Ledgerline: first timesheet entry, even if it is only induction time
- [ ] Meet your pod lead and read the engagement brief
- [ ] Read the glossary and the FAQ in `docs/faq.md`

## Day 4
- [ ] Shadow a pod stand-up
- [ ] Git access requested, if your role needs it

## Day 5
- [ ] Short chat with your buddy: what was confusing?
- [ ] Raise a ticket or PR for anything wrong in these guides
