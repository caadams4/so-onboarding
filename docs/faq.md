# FAQ from the summer intake

**Why does the tracker URL say jira?**
Historical. See the tools guide.

**Can I use my own phone for the authenticator?**
Yes. Corporate IT can enrol a new device if you change phones.

**My VPN shows a handshake but nothing loads.**
Try the MTU setting in the VPN guide.

**Do I need git access in week one?**
Probably not. Ask your pod lead.

**Where do I put client files?**
On the engagement share, not your laptop.
